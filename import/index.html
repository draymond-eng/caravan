Move Japan 2027 in

A one-time copy of the old standalone app's content into a SquadTrip trip. Run it once, on a trip you have just created. It only ever adds; it never deletes anything that is already there.

1. Which trip?

The join code from the trip you made on joinsquadtrip.com.

2. When does it start?

Day one in Japan. You land Thu Apr 15 on UA 881 and fly home Sat Apr 24 on UA 882, which is what the itinerary below is built around. Change this and every day shifts with it, keeping the same order and length.

3. What moves across

    The trip's own details (name, dates, timezone, the three cities and the six travelers) are overwritten to match Japan 2027. Everything else is added alongside whatever is already on the trip.
